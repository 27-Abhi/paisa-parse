# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |

## Reporting a Vulnerability

`paisa-parse` is a pure-Python text parser with zero runtime network or filesystem dependencies. If you discover a security issue (such as ReDoS on pathological inputs or an issue in an integration adapter), please open a private security advisory on GitHub at:

https://github.com/27-Abhi/paisa-parse/security/advisories/new

or email `abhinavkuppasad27@gmail.com`.
